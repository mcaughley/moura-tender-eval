# Banana Shire Council Tender Evaluator

Simple Streamlit app to evaluate tenders against Part 6 Response Schedules.

## How to use
1. Add each tender by name
2. For each tender, upload one file per category
3. Click "Evaluate All Tenders"
4. View ranking and per-category scores

## Deploy
- Push to GitHub
- Deploy free on [Streamlit Cloud](https://share.streamlit.io)
- Add your Groq API key in Secrets (key = `GROQ_API_KEY`)
